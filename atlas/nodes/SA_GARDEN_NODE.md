# NODE-SA-01 — South African Garden Node

**Status:** canonical prototype, v0.1  
**Region inspiration:** inland from South Africa's Garden Route, near the Outeniqua / Klein Karoo transition  
**Exact location:** fictional

## Narrative function

NODE-SA-01 is the first fully modelled Kastel node.

It is intended to demonstrate how a Red Rail community can remain connected to ordinary economic life while maintaining meaningful local capability.

The node is not a fortress or survivalist compound. It is a comfortable, productive, technologically sophisticated rural base.

## Core components

### Main house
- modest modern modular or masonry house;
- high insulation;
- shaded outdoor living;
- locally appropriate materials;
- control room / study;
- private computing area;
- flexible guest rooms;
- strong fire-conscious detailing.

### Technical core
- local server/storage stack;
- local AI workstation;
- redundant networking;
- offline knowledge library;
- Home Assistant-style local control;
- cameras and environmental sensors;
- battery-backed communications.

### Workshop
- woodworking;
- basic metalwork;
- electronics bench;
- 3D printing;
- repair area;
- component storage;
- computer/CAD terminal.

### Productive land
- orchard;
- perennial planting;
- intensive kitchen garden;
- greenhouse or shade house;
- composting;
- water-retentive landscaping;
- soil and irrigation monitoring.

### Water
- large rainwater storage;
- domestic reserve;
- irrigation reserve;
- protected fire-water reserve;
- pump redundancy;
- level and flow sensing.

### Resilience
- wildfire-conscious landscape;
- non-combustible zone near buildings;
- remote weather/smoke sensing;
- flood/runoff monitoring where terrain requires;
- multiple communications paths;
- safe refuge room;
- verified emergency/security response.

## Residency model

The node is designed to remain viable for several weeks with automation and periodic inspection.

Longer absences favour rotating stewardship.

The system should support:

```text
automation handles routine operation
human residents handle exceptions
the knowledge base preserves institutional memory
```

Potential residents include owners, trusted friends, visiting researchers, remote workers, land stewards and collaborators.

## Economic base

Plausible Blue Rail income may include:

- remote professional work;
- software;
- digital products;
- trading/research;
- consulting;
- education;
- design;
- selective local production.

The node may also produce local goods, but should not be written as economically self-sufficient.
