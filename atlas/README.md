# Kastel Atlas

The Atlas is the persistent spatial and institutional reference for Kastel World.

It records:

- global and regional geography;
- fictional nodes;
- towns and cities;
- routes;
- buildings;
- site plans;
- infrastructure;
- persistent story state;
- links between places and issues.

## Atlas rule

The Atlas is not decorative lore. It exists to keep the world spatially coherent.

A location should answer:

- Where is it?
- What surrounds it?
- How is it reached?
- What does it depend on?
- What can fail?
- What changes after an event?
- Which characters are usually present?
- What practical systems are visible there?
