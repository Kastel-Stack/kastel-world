# Reality / Fiction Boundary

Kastel World deliberately connects fiction to real technology. That makes boundary discipline essential.

## Four status labels

### REAL NOW
A capability that can be built or bought now using mature technology.

### EXPERIMENTAL
A capability that exists but is immature, expensive, specialist or unusually demanding.

### PROJECTED
A plausible extension of present trends that is not yet reliably available in the form shown.

### FICTIONAL
A narrative invention with no claim of current feasibility.

## Rules

1. Every technology page must display a status.
2. A PROJECTED item must name its current technical ancestors.
3. A FICTIONAL item must not be linked to a "build this now" page as if it were real.
4. Cost and capability claims should be dated.
5. Safety-critical material must distinguish conceptual architecture from qualified engineering.
6. Medical, legal, financial, radio, electrical and building-code boundaries must be identified where relevant.
7. Security material should prioritise detection, resilience, refuge and lawful response rather than confrontation.
8. Fictional institutions must not be presented as real organisations.
9. Real places may inspire fictional settings, but sensitive private details should not be exposed.

## Geographic sources

For publishable production assets, prefer:

- OpenStreetMap and compatible open data;
- national mapping/open-data portals;
- Copernicus and other licensable Earth-observation data;
- self-created photography;
- commissioned/licensed imagery;
- owned 3D models.

Google Earth and Street View can be useful for private observation and orientation, but are not the canonical production substrate.

## Core question

For every page ask:

> **What exactly is real here, and what evidence supports that status?**
