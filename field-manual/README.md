# Kastel Field Manual

The Field Manual is the real-world layer beneath the fiction.

It explains technologies and practices shown in Kastel stories without pretending the fictional system already exists.

## Entry format

Every entry should state:

- reality status;
- what it meaningfully lets a person do;
- how difficult it is;
- rough cost band;
- internet dependence;
- open/self-hosted status;
- safety/legal boundary;
- official links;
- relevant Builds;
- comic appearances;
- last review date.

## Evidence discipline

The Field Manual is not a shopping affiliate catalogue.

Prefer primary documentation and open project sources. When a claim is uncertain, say so.
