# Roadmap

## Phase 0 — Ground truth

- establish project vision and repository boundaries;
- define Blue Rail and Red Rail;
- define reality-status labels;
- define comic-to-Field-Manual linking;
- establish spatial canon standards;
- create first node scaffold;
- establish practical-content safety rules.

## Phase 1 — Minimum viable world

Build enough fixed reality to support the first story:

- one primary node: South African Garden Node;
- one Blue Rail urban setting;
- one regional transit corridor;
- one or two satellite nodes;
- 8–12 recurring character concepts;
- world timeline v0.1;
- basic political/economic background;
- first house/compound plan;
- first regional terrain model;
- first visual style guide;
- 10 reusable story engines.

## Phase 2 — Spatial production pipeline

- choose canonical geography sources;
- create QGIS base map;
- create first site model;
- create modular house model;
- dress key interiors;
- establish named cameras;
- establish environment-state versioning;
- create character test models;
- test 3D render → comic line/style workflow;
- produce one test page.

## Phase 3 — Issue Zero

Issue Zero should demonstrate the full stack:

- entertaining self-contained story;
- South African Garden Node;
- one environmental hazard or infrastructure problem;
- one Blue Rail interaction;
- one practical technology marker;
- one node marker;
- one Build marker;
- Field Manual links working on the website.

## Phase 4 — Public website

Launch:

- Comic;
- Atlas;
- Vision;
- Field Manual;
- Builds;
- Commons;
- Community;
- reality-status system;
- interactive cross-links between fiction and reality.

## Phase 5 — Community builds

- accept build logs;
- establish contribution rules;
- test community improvements;
- publish verified amendments;
- introduce localisation notes;
- distinguish tested community practice from unverified suggestions.

## Phase 6 — Expanding world

Add nodes only when they contribute a distinctive ecology or story function, for example:

- Montenegro mountain node;
- Portuguese Atlantic node;
- dense urban Blue Rail node;
- Balkan transit house;
- Southern African coastal/trade node;
- later Latin American or Asian nodes.

## Phase 7 — Interactive world

Potential later directions:

- interactive Atlas;
- explorable 3D node models;
- persistent world-state database;
- reader-facing node cutaways;
- downloadable public models;
- educational workshops;
- selected open-hardware kits.

The project should resist premature complexity. The first success condition is not a complete universe; it is one coherent place, one strong recurring community and one genuinely enjoyable issue.
