# Community

The Kastel community is the real-world experimentation layer.

Its purpose is not to create a political cadre. It is to help people share practical, lawful work around:

- local AI;
- resilient computing;
- communications;
- mapping;
- open hardware;
- environmental sensing;
- permaculture;
- water;
- workshops;
- repair;
- resilient architecture;
- comic/worldbuilding;
- build logs.

## Community loop

```text
Field Manual idea
→ Build
→ field test
→ build log
→ criticism
→ revision
→ validated improvement
→ Commons
```

## Norms

- distinguish tested from speculative;
- show failures as well as successes;
- disclose commercial interests;
- respect privacy;
- do not expose sensitive private locations;
- do not publish harmful operational security material;
- prefer repairable/open approaches where practical;
- welcome different levels of technical ability.

## Contribution types

- build log;
- bug report;
- alternative parts list;
- localisation note;
- safety correction;
- cost update;
- documentation improvement;
- comic continuity correction;
- new node concept;
- visual asset contribution.
