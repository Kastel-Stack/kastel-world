# Character Canon

Every recurring character should have a permanent entry.

Minimum fields:

- ID;
- name;
- age range;
- node affiliation;
- occupation/livelihood;
- role in community;
- skills;
- weaknesses;
- temperament;
- comic tendencies;
- relationships;
- Blue Rail dependencies;
- Red Rail responsibilities;
- wardrobe;
- tools/vehicle;
- personal spaces;
- visual model status.

Characters should not exist only to embody ideologies.

A strong Kastel character should be useful in one situation, difficult in another and capable of being wrong.
